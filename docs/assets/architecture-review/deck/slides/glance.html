One GitHub Actions run per review; no server, database, or queue · 3

Two jobs never share credentials (ADR-001). The review job has read-only permissions and holds the model key and the Jira credentials; it is the only place the LLM is called. The comment job holds pull-requests: write and no secret; it publishes result.json through fixed templates after re-checking the head SHA. Forks are stopped at the gate before checkout. The pull request’s own text (title, description, branch, commits) is read by the tool only to find the requirement ID and the language; it never reaches the model.
