docs/decisions/ in the repository · ADR-005 supersedes ADR-003 · 18

ADR-001 splits credentials: the review job is read-only with the model and Jira secrets; the comment job has pull-requests: write and no secret. ADR-002 gives the agent a fixed input plus three read-only tools over the head-SHA checkout, refusing excluded and outside paths, capped at 40 calls and 400,000 characters, with every chunk hashed. ADR-003 first planned a read:packages token stored per adopter; ADR-005 replaced it with the caller’s own GITHUB_TOKEN and a Read role granted on the package. ADR-004 picks the Agent Framework workflow and a provider-agnostic IChatClient. ADR-006 adopts the pr-review method and format and the untrusted-input boundary: randomized block tags and a tripwire outside the model.
