Everything is one .NET 10 console app published as a .NET tool. GitHub clients are plain HttpClient with System.Text.Json; there is no CLI parser, YAML library or logging framework. Requirement sources live under Requirements/: the REQ entry reader and the Jira Cloud client with its Atlassian Document Format converter. The domain records (ReviewResult, Finding, Coverage, Fingerprint, ContextSnapshot) are what result.json carries between the jobs.
