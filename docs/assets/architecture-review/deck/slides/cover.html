Architecture review

Integricode

An AI pull-request reviewer that publishes only what code can verify

GitHub Actions · .NET 10 · Microsoft Agent Framework · v1.1.1

Integricode reviews a pull request when it becomes ready for review, checks it for bugs and against its linked requirement (a REQ entry or a Jira Cloud issue), and posts evidence-backed findings. This deck walks through the architecture, with the LLM part in detail, and ends with the decisions taken and the known limits. The companion document “Integricode Architecture Deep Dive” has every detail behind these slides.
