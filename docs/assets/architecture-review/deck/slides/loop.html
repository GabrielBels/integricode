ChatClientAgent with ResponseFormat = JSON schema · ADR-002 · 11

The review executor creates a ChatClientAgent with the instructions, the three tools through function calling, and ResponseFormat set to the JSON schema. The model decides when it has read enough. Every tool call goes through PathGuard (no absolute paths, no “..”, no symbolic link leaving the checkout, no excluded path) and the ContextBudget of 40 calls and 400,000 characters, shared with the prompt’s files. A refused call answers with the reason, so the model can carry on. Each returned chunk is recorded with its path, line range and SHA-256 for the context hash. Each tool call resends the conversation, so input tokens grow with tool use. The reply is parsed from its first “{” to its last “}”.
