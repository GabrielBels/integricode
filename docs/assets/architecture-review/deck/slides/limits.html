Bugs are reported only on changed lines; there is no memory across PRs.

Measured on the first adopter’s PRs 70 and 72 · 19

Non-determinism: on PR 72, one run reported a broken test as a second blocker and the next run on the same commit did not; wording changes too, so fingerprints change and comments get minimized and re-posted. Cost: input tokens ranged from about 5,000 to 135,000 on the same one-line change, driven by tool calls; the only caps are 40 calls and 400,000 characters. Large PRs keep running but with incomplete coverage once the budget is spent. Language detection is a word-count heuristic; short or mixed texts fall back to the language input. While the repository and package are private, only repositories under the same GitHub account can call the workflow.
