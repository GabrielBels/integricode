ChatClientFactory picks the SDK from the model-provider input. OpenAI and Azure OpenAI both go through the OpenAI .NET SDK via Microsoft.Extensions.AI.OpenAI; Azure uses the resource’s OpenAI-compatible v1 endpoint, with the model input as the deployment name. Claude goes through the official Anthropic SDK, with an 8,192-token output limit unless set. The SDKs’ own retry policies are disabled and a RetryingChatClient retries once on 429 or any 5xx, resending the same message history. A provider failure becomes coverage “failed” with “model provider error (HTTP n)”: the provider’s message is never logged or published because it can echo prompt content. The first adopter picks the model per PR from an “AI Review” section in the description, defaulting to claude-sonnet-5-5.
