Pushing a vX.Y.Z tag runs release.yml: build, test, pack with that version, push to the private GitHub Packages feed, and move the vX tag. The reusable workflow installs 1.* with the caller’s GITHUB_TOKEN; the owner grants each adopter the Read role on the package (ADR-005). Adoption is one caller workflow and one secret per model provider. Observability is the Actions log of each run (language, requirement, coverage, counts by kind and light, dropped counts by reason, lenses, injection warning locations, context hash, token usage) plus a machine-readable record in the summary comment; nothing else is stored. The three runs in the table used the same commit; v1.1.0 introduced the pr-review method and lenses, which grew the system prompt, and that run also made six tool calls.
