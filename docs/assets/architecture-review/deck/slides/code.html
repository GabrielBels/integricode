Program wires App to the console and the network; App dispatches on the first argument and builds the GitHubClient, the IChatClient from ChatClientFactory, and the optional Jira source from environment variables. ReviewCommand fetches the pull request, its files with patches and its commit messages, resolves the language, and runs ReviewWorkflow. The workflow is three executors bound with BindAsExecutor and wired with WorkflowBuilder: GatherContextAsync builds the fixed input, ReviewAsync runs the agent (the only step that calls the model), and ValidateAsync applies the deterministic checks and yields the typed ReviewResult, written to result.json. CommentCommand runs in the separate comment job and publishes that file.
