CommentCommand + CommentTemplates · REST for comments and reviews, GraphQL to minimize · 13

The comment job turns result.json into two kinds of GitHub objects. It first re-reads the pull request: if the head SHA moved, nothing is published and the summary says superseded (and a late, older result never replaces a newer summary). The summary is found by its integricode:summary marker among comments by github-actions[bot] and updated in place. Each inline comment carries an integricode:finding marker with its fingerprint; a fingerprint already visible is not posted again, and visible Integricode comments whose fingerprint the new result no longer reports are minimized with reason OUTDATED through the GraphQL minimizeComment mutation. Because a fingerprint covers the wording, a rephrased finding is minimized and re-posted; that happened on the real re-run of PR 72. Everything published goes through CommentTemplates: length caps, HTML escaping, neutralized @ mentions, escaped brackets.
