# Architecture Review Material

Material prepared to present Integricode's architecture to the company's architects, archived on 2026-11-04 from the version shared on claude.ai.

- [architecture-deep-dive.md](architecture-deep-dive.md): the companion document, with every detail behind the slides. Its two diagrams are Mermaid, which GitHub renders.
- [deck/](deck/): the 19-slide deck as its source files, `deck.json` (title, slide order, sections, fonts) and one HTML file per slide in `slides/`, with speaker notes in each slide's `<aside>`.
